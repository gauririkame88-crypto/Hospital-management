# Hospital Management System Database (SQL Project)

## 📌 Project Overview
The Hospital Management System is a database project developed using SQL.
It is designed to manage hospital data such as patients, doctors, rooms,
laboratory records, and billing information efficiently.

This project focuses on database design and SQL queries used in real-world
hospital management systems.

---

## 🛠️ Technologies Used
- SQL
- MySQL
- MySQL Workbench / phpMyAdmin

---

## 📂 Database Tables
The database contains the following tables:

- patient
- doctor
- inpatient
- outpatient
- room
- labrotory
- bill

---

## 🔗 Key Features
- Patient record management
- Doctor details storage
- Inpatient and outpatient handling
- Room allocation system
- Laboratory test records
- Billing and payment management
- Proper use of Primary and Foreign Keys

---

## 📑 SQL Concepts Used
- CREATE TABLE
- INSERT
- SELECT
- UPDATE
- DELETE
- JOIN
- WHERE
- GROUP BY
- Aggregate functions

---

## ▶️ How to Run the Project
1. Create a database in MySQL (example: hospital)
2. Import the SQL file into MySQL
3. Execute the queries
4. View and manage hospital data
